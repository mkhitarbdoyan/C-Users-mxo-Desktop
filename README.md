# ArmJob

ArmJob is a modern jobs and community classifieds board for the Armenian community in Los Angeles — inspired by [ArmenianBD.com](https://armenianbd.com), with a cleaner product experience.

## Features

- **Jobs** — browse, filter by location/category/type, view details, post a listing
- **Resumes / job wanted** — candidate listings
- **Housing** — apartments and ADUs
- **Cars** — for sale and rideshare rentals
- **Events** — community gatherings
- **Business directory** — local services with phone and hours

Sample data only — no backend or auth yet.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm run lint
```
